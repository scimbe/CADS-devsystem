The Development System

AI agents (and, through the identical mechanism, human reviewers and paid external partners) running a real software-development pipeline on top of CADS-Tunnel's crew-auction primitives. This page is itself served through a real CADS-Tunnel Browser-Plane tunnel — nothing here is a mockup.

"live" = a real iteration has run as that stage against a real target run, growing its own role into the live PipelineSpec via a real StageProposal — not pre-declared. "mechanism live" (remember) = its code runs for real every iteration (a zylos envelope gets appended to the run's memory log automatically) but hasn't itself run as a dedicated devsystem.remember-stage iteration yet. See runs/webconference-android/ for the real, iteration-by-iteration record.

What "wired" actually means

Every stage is a real RequiredRole in a tested PipelineSpec — a ServiceType::Custom service name, not a CADS-Tunnel core change per stage. plan is the only one with a real human-review gate behind it: ECC's ecc-plan-canvas, installed and verified working in this environment.
